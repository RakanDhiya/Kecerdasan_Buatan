# Artificial Intelligence – Python Implementations

Repository ini berisi kumpulan implementasi algoritma dan konsep **Kecerdasan Buatan (Artificial Intelligence)** menggunakan bahasa pemrograman Python.

Project ini dibuat sebagai dokumentasi pembelajaran dan praktikum untuk memahami berbagai metode, algoritma, serta penerapan dasar Artificial Intelligence melalui program sederhana.

## 📚 Daftar Materi

Berikut adalah materi yang tersedia di repository ini:

| No. | Materi | Deskripsi |
|---|---|---|
| 1 | [Depth First Search](./Depth-First-Search/) | Implementasi algoritma pencarian graf menggunakan metode Depth First Search (DFS). |
| 2 | [Inferensi dan Representasi Pengetahuan](./Inferensi-dan-Representasi-Pengetahuan/) | Implementasi konsep representasi pengetahuan dan proses inferensi dalam AI. |
| 3 | [Neural Network](./Neural-Network/) | Implementasi jaringan saraf tiruan menggunakan PyTorch, termasuk Neuron, MLP XOR, dan CNN MNIST. |
| 4 | [Perceptron dan Delta Rule](./Perceptron-dan-Delta-Rule/) | Implementasi algoritma Perceptron dan Delta Rule menggunakan Python dan NumPy. |
| 5 | [Sistem Pakar dan Forward Chaining](./Sistem-Pakar-dan-Forward-Chaining/) | Implementasi sistem pakar menggunakan aturan (rules) dan metode inferensi Forward Chaining. |

## 🛠️ Teknologi yang Digunakan

- **Python 3.11** – Bahasa pemrograman utama.
- **NumPy** – Pengolahan data numerik dan operasi array.
- **PyTorch** – Framework untuk implementasi dan pelatihan Neural Network.

## ⚙️ Persiapan

Pastikan Python sudah terpasang di komputer.

Periksa versi Python:

```bash
python --version
```

Beberapa materi menggunakan library tambahan. Instalasi library dapat disesuaikan dengan kebutuhan masing-masing program dan petunjuk pada README di setiap folder materi.

Contoh instalasi:

```bash
pip install numpy torch torchvision
```

## ▶️ Menjalankan Program

Setiap materi memiliki folder dan file Python masing-masing.

Masuk ke folder materi yang ingin dijalankan, kemudian eksekusi file Python melalui terminal.

Contoh:

```bash
cd Depth-First-Search
python dfs_rekursif.py
```

Nama file dan kebutuhan library dapat berbeda pada setiap materi. Silakan lihat README di dalam folder terkait.
